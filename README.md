
# Flowify
A modern and fully responsive SaaS landing page built with pure HTML5 and CSS3.

⚡Technical Capabilities


 **Fully Responsive:** Seamlessly optimized for Mobile, Tablet, and Desktop viewports using media queries.
 
 **Modern UI/UX Architecture:** Built with clean, accessible components using CSS Grid & Flexbox layouts.
 
 **Dynamic CSS Variables (`:root`):** Centralized theme management featuring a custom **Midnight Indigo** color palette.

 
🧩 Page Components

 **Header & Navigation:** Sticky, sleek Navbar with high-converting CTA buttons.
 
 **Hero Section:** Engaging headline, value proposition, action buttons, and dashboard preview.
 
 **Features Grid:** Highlighting core platform benefits inside responsive cards.
 
 **Pricing Cards:** Tiered plans (*Pro*, *Business*, *Enterprise*) with a highlighted *"Most Popular"* badge.
 
 **About & Metrics:** Company mission statement paired with key performance stats.
 
 **Footer:** Multi-column links layout with a refined copyright bar.
